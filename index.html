2 — فتح مشروع ZIP

ارفع مشروعاً مضغوطاً بصيغة ZIP. سيتم فكّه داخل CodePilot2 مباشرة. سيظهر الكود والمعاينة فوراً؛ أما تثبيت dependencies وتشغيل Node/React ونحوها فيحتاج إلى تشغيل Build عبر GitHub Actions.

لم يتم اختيار ملف ZIP.
بعد رفع ZIP: ينشئ CodePilot2 مستودعاً، يثبت dependencies، يبني المشروع، ثم ينشره على GitHub Pages.

ملاحظة هندسية مهمة

GitHub Pages هو الواجهة فقط. GitHub Actions هو محرك التنفيذ، وGitHub App هو طبقة المصادقة. لا توجد Vercel ولا /api/* ولا Personal Access Token داخل الصفحة.
