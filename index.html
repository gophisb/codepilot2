CodePilot2

مولّد تطبيقات يعمل بهندسة GitHub فقط: الواجهة ثابتة على GitHub Pages، والتنفيذ والـAI داخل GitHub Actions. لا توجد مفاتيح سرية داخل المتصفح.

فتح GitHub Actions
جاهز. اضغط «توليد المشروع الآن» لنسخ طلب مضبوط وفتح GitHub Actions.

مهم: GitHub Pages موقع ثابت ولا يشغّل /api أو Node.js. لذلك لا نحاول إرسال أسرار GitHub أو مفاتيح AI من المتصفح. هذا يمنع تسريب المفاتيح ويحافظ على هندسة GitHub-only.

المسار الصحيح
1. CodePilot2 على GitHub Pages يبني الطلب فقط.
2. GitHub Actions ينفذ الذكاء الاصطناعي باستخدام Secrets.
3. يتم إنشاء مستودع مستقل للمشروع ونشر الملفات فيه.
4. نتيجة التشغيل ورابط المستودع تظهران في GitHub Actions، مع Artifact للملفات المولدة.
لماذا أزلنا /api؟

وجود /api/generate و/api/health في مشروع منشور عبر GitHub Pages كان سبب العطل المعماري: الملفات يمكن أن توجد في المستودع، لكن GitHub Pages لا يحولها إلى Backend. الإبقاء عليها كان يعطي الواجهة انطباعاً أن الخادم موجود بينما هو غير موجود.
