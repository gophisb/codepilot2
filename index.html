ملاحظة هندسية مهمة

لا نحاول إحياء /api/generate داخل GitHub Pages. هذا كان سبباً معمارياً حقيقياً للعطل السابق. GitHub Actions هو محرك التنفيذ، وCodePilot2 هو واجهة التحكم والعرض. ولتفعيل زر «توليد» من الصفحة بدون فتح Actions مستقبلاً نحتاج مصادقة GitHub آمنة (GitHub App/OAuth)؛ لن نضع Personal Access Token داخل الصفحة كحل سريع.
