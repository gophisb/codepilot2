CodePilot

مولّد تطبيقات عملي: اكتب الفكرة، ولّد المشروع، شاهد الملفات، انسخ الكود يدوياً، ثم جرّب معاينة HTML/PWA مؤقتة. وتبقى أدوات GitHub Actions السابقة متاحة.

فتح CodePilot في GitHub Actions
جاهز. يمكنك التوليد من الواجهة أو استخدام GitHub Actions كما في السابق.

المفاتيح لا تظهر في الواجهة؛ التوليد المباشر يمر عبر /api/generate. GitHub Actions يبقى مساراً مستقلاً.

المشروع الناتج

—يمكنك تعديل النص ثم نسخه يدوياً

المعاينة السريعة تعمل عندما يحتوي المشروع على index.html. وهي معاينة مؤقتة داخل المتصفح وليست بناءً نهائياً للتطبيق.

ماذا يحدث؟

يمكنك استخدام الواجهة للتوليد والعرض والنسخ اليدوي، أو فتح GitHub Actions للمسار السابق الذي ينشئ مستودعاً مستقلاً للمشروع. لا يتم تعديل main تلقائياً من المعاينة.
